## About this entry

A single-line roast (143 characters) of wireless earbuds and their
most recognisable habit: only one bud ever goes missing, and it
always turns up days later in a pocket, acting like it belongs
there. The program in `main.ts` holds the line as a constant,
checks its length against the 200-character cap, and writes it
as UTF-8 text to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

By default the line is written to `/output/entry.txt`. Set the
`OUTPUT_DIR` environment variable to write it somewhere else:

```sh
OUTPUT_DIR=/tmp/test-out-roast node main.ts
```
